# Loopsy Cakes

This is a Next.js website project prepared for Vercel.

## Deploy with Vercel

1. Unzip this folder.
2. Push the extracted project to a GitHub repository.
3. Import that repository in Vercel. Vercel will detect Next.js.
4. Use the default build command: `pnpm run build`.

The project uses Node.js 22 or newer and the included `pnpm-lock.yaml` to keep dependencies consistent. The cake inquiry form is a visual demo and does not send orders anywhere.
